# Risk Model Agent

一个本地优先、人工确认后才训练的二分类信贷风控建模 Agent。

它面向风控分析师完成 CSV 数据体检、建模方案生成、审批、候选模型训练、留出集评估和可审计报告。V1 的 Agent 是规则化、只读的流程助手；数据计算与指标全部由本地确定性代码完成。

> 本项目是建模决策支持与离线实验工具，不是自动授信系统。输出不代表生产效果、业务收益、公平性或监管合规性。

## V1 能力

- 单个 CSV、单行一笔申请、一个二分类标签
- 字段类型、缺失、重复、常量、疑似 ID、高基数和启发式泄漏体检
- 标签正类、排除字段与随机/时间留出切分方案
- 数据集哈希、方案版本、批准哈希、不可变 Run ID 和审计事件
- Dummy 基线、逻辑回归和随机森林候选模型
- 训练集 OOF 选模，阈值仅在 OOF 中确定，留出集一次性评估
- ROC-AUC、KS、PR-AUC、Brier、阈值指标与十分位 Lift
- 规则化 Agent 对事实、风险和建议进行分层解读
- 自包含 HTML 报告；报告不包含逐行客户数据

V1 不包含在线评分、自动授信、模型部署、生产监控、外部数据连接、合规认证或真实 LLM 调用。

## 本地启动

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

然后访问 <http://127.0.0.1:8000>。

所有上传数据、模型、报告与审计数据库默认写入 `instance/`，该目录内容不会提交到 Git。也可通过 `RISK_AGENT_INSTANCE_DIR` 指向另一个本地私有目录。

## 验证

```bash
.venv/bin/python -m pytest
.venv/bin/python -m ruff check .
```

仓库附带的演示数据是运行时生成的合成样本，只用于验证工程流程。

## 数据与权限边界

- 服务默认只监听 `127.0.0.1`。
- V1 不包含任何外部网络调用或 LLM Provider。
- Agent 只有读取画像、方案和结果的能力，不能访问 Shell、批准方案、部署模型或作授信决定。
- 修改数据、标签或方案会使旧批准失效；训练再次核对方案哈希。
- 泄漏检测是启发式筛查，不能代替字段血缘与业务发生时间复核。

详细产品边界、架构与验证说明见 `docs/`。
