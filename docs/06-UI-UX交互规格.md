# 06｜专业建模台 UI/UX 规格

## 1. 固定骨架

- 左侧：项目列表、新建项目、本地/网络边界和设置入口。
- 中间：当前工作台、产物报告、历史 Run 三个一级视图。
- 右侧：当前阶段、Agent/Reviewer/工具/Checkpoint/事件序号和下一步。
- 中间底部：始终展开的项目 Agent 对话。

该结构在 1440×900 和 1280×800 保持一屏骨架；中间内容区独立滚动，页面本身不横向溢出。

## 2. 首次使用

空状态直接解释本地数据边界和三步价值，主行动为“创建第一个项目”。创建弹窗只要求项目名称和协作模式；机构、产品和说明可选。固定种子合成项目入口与真实上传入口并列，但所有演示数据必须有明确合成标记。

## 3. 数据工作台

二级页签：导入、关联、Y 任务、Notebook。用户可以按顺序操作，也可在有明确前置条件时直接进入某页。关联页同时呈现四级兜底，不把 Notebook 藏在设置里。

所有异步操作显示忙碌、成功或错误反馈；文件导入后展示用途、文件名、格式、规模、状态/Sheet 和下一步。

## 4. 确认卡

每张卡包含：阶段、业务标题、Run/Checkpoint、Reviewer 结论、关键数字、可编辑字段、证据详情、停止和确认按钮。默认只展示业务摘要；长证据按需展开。拒绝按钮不能与继续按钮同色。

变量恢复先填写至少 8 个字符理由，再允许勾选；不可恢复字段不进入可恢复表。人工分箱明确提示会生成新版本并使训练、审核和报告失效。

## 5. 运行与报告

运行页显示整体进度、Champion、AUC/KS、排序性、候选矩阵和最近事件。指标达标但绝对排序不满足时，标题必须是“需关注排序”或“条件通过”，不能写“无问题”。

报告首页先给管理摘要，再提供 Train/Test/OOT、候选模型、模型分箱和最终入模变量。评分入口放在报告末尾，上传后直接提供带模型名列的结果下载。

## 6. 设置中心

集中管理 Provider、API 格式、Base URL、主/Reviewer 模型、密钥、默认算法、内存、并发、Notebook 网络、代理、CA、更新、遥测、Token 预算、备份和重置。设置入口不藏在项目二级页。

## 7. 可访问性

- 一级和二级页签使用 `tablist/tab/tabpanel`、`aria-selected`、roving tabindex，并支持左右键、Home、End。
- 弹窗/抽屉使用 `dialog`、`aria-modal`、标题关联、焦点圈定和 Esc 关闭。
- 打开时焦点进入弹窗，关闭后回到原入口。
- 所有输入有可访问名称；状态消息使用 `role=status`，颜色不是唯一状态信号。
- 200% 缩放和常见笔记本尺寸下仍能完成核心流程。

## 8. 必测页面状态

空项目、已导入、Sheet 待选择、关联阻断、运行中、等待确认、用户拒绝、模型候选局部失败、条件通过、成功报告、无 LLM 降级、Provider 连接失败、评分字段缺失和资源降级。
