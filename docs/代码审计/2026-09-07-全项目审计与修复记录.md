## 升级与使用变化

1. 目标版本为 **1.2.2**；无需清空用户数据。本次未提高数据库 Schema 版本。
2. Suite 定义变更必须使用新 ID。旧的不完整评测证据可能无法通过新门禁，不能用旧通过结论代替重跑。
3. `scripts/run_harness.py --async` 依赖已运行的普通本机 Web 服务；桌面私有会话未授权时会明确失败，不会绕过认证。
4. 数据文件哈希不匹配时，请重新导入为新资产/数据版本；不要修改数据库哈希来掩盖差异。
5. 重新训练后模型包使用安全文件名，模型显示名和评分列语义不变。既有模型与项目文件保留。
6. wheel 离线脚本在目标 OS/Python 上验证。Windows EXE 的发行验证与 wheel 脚本的单元测试是两条不同证据，不能互相替代。
