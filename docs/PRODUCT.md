# 产品边界

## 定位

Risk Model Agent 是一个本地优先的风控建模决策支持工具，面向需要快速完成数据体检、方案审阅和离线实验的风控分析师。它不是自动授信系统，也不直接输出拒绝、通过或调额决定。

## V1 工作流

1. 导入一份 CSV，保存文件哈希并生成聚合画像。
2. 选择二分类目标和坏样本取值，核验字段、时间和泄漏提醒。
3. 生成带版本号和 SHA-256 的结构化建模方案。
4. 人工完成标签、字段、切分和离线方案确认。
5. 本地确定性 Worker 在训练分区做 OOF 候选比较，锁定阈值后只用一次留出集评估。
6. 生成不可变 Run ID、结果 JSON、模型文件和 HTML 报告。
7. 规则化 Agent 只读取上述本地产物，区分事实、风险与建议。

## 证据边界

- 演示 CSV 是合成数据，只证明流程可运行。
- ROC-AUC、KS、PR-AUC、Brier 和 Lift 是指定数据与切分下的离线实验指标。
- 泄漏检测是启发式筛查，不能代替字段血缘、标签窗口和决策时间复核。
- 没有外部 LLM、外部数据连接或生产部署能力；Agent 不能批准方案、执行 Shell 或作授信决定。

## V1 不做

多分类、回归、图片/PDF、自动特征生成、无限 AutoML、在线评分、模型注册与灰度、线上漂移监控、公平性认证和监管合规认证均不在本版本范围内。
