# 08｜验收标准与测试场景

## 1. 固定黄金数据

使用固定种子的客户/订单合成数据：订单主表、客户画像表、征信表、设备表、数据字典；包含 FPD0、FPD7、MOB30 及 `0/1/-1/空值`。黄金 Run 必须从关联跑到报告、模型重载和新样本评分。

合成结果只证明流程与一致性，不代表真实模型效果或生产稳定性。

## 2. 数据与关联

- CSV 编码、XLS/XLSX/XLSM、多 Sheet、数据字典缺失码。
- 一对一、多对一、组合键、低匹配、重复键、异常膨胀。
- Agent 推荐、可视化、Agent Notebook、用户 Notebook 输出均重新校验。
- 多个 Y 各自排除 `-1/空值`，其他 Y 不得入模。

## 3. 建模正确性

- Train-only 筛选、分箱、预处理、类别权重和校准。
- 客户跨 Train/Test/OOT 交集为零；时间 OOT 锁定。
- IV、WOE、PSI、AUC、KS、PR-AUC、Lift、Brier 和评分转换用可验证样本测试。
- PII、泄漏、主键和贷后字段不可恢复；普通字段必须有理由。
- 人工分箱生成新版本；非单调方案拒绝并触发下游失效。
- 候选局部失败隔离；无 Champion、指标缺失和 OOT 选模阻断。
- 未校准、Platt、Isotonic 选择范围正确。

## 4. Agent 与 Reviewer

- 半信任每个关键 checkpoint 可暂停、重启和恢复。
- 完全信任自动继续但不能绕过安全阻断。
- Reviewer 独立上下文，最多三轮反馈/修复；无 LLM 时明确确定性降级。
- 事件包含序号、阶段、节点、Agent、工具、状态、摘要、时间和证据，不含隐藏思维链。

## 5. 安全

- 原始行、文件路径、PII、密钥和表格自由文本外发被拒绝。
- 小于 30 的分组抑制。
- 环境变量密钥不可在页面伪清除；本地密钥不回显。
- 归档 AES-256-GCM 认证、错误密码、恢复密钥、篡改、路径越界和 checksum。
- 模型包、报告和评分文件 checksum 验证。

## 6. 产物一致性

- JSON、Web、Excel、HTML 的 Champion 和核心指标一致。
- Excel 前三个 Sheet 名称和内容符合规格。
- 条件质量结论在所有格式中一致显示。
- 模型持久化后重载评分与训练时结果一致，评分列使用模型名称。

## 7. 资源

使用约 3 万行、1000 字段合成数据验证资源计划。Worker 可按列和按行分批，模型并发受限；8GB 机器上不得卡死系统。资源不足必须明确降级/延期，不得静默抽样或删行。

## 8. Web 与可访问性

1440×900 和 1280×800 检查四区布局、内部滚动、空/阻断/运行/完成状态。键盘验证一级/二级页签、弹窗/抽屉 Esc、焦点进入与返回、输入名称和状态消息。浏览器控制台不得有运行错误。

## 9. 迁移与跨平台

- 旧数据库先快照；项目/数据数量、复制文件树和哈希一致；旧 Run 只读。
- macOS 13+ Apple Silicon 本机构建与 localhost 冒烟。
- Windows 10/11 x64 由 Windows runner 构建与冒烟。
- 未完成签名安装、升级/卸载及真实目标机验收前，不宣称正式安装支持。

## 10. CI 门禁

Python 3.11/3.12/3.13 lint 和 pytest；Node 22 typecheck/build；API、黄金数据、报告一致性、迁移、归档、Notebook、打包规格检查；macOS/Windows 打包 workflow 生成候选 artifact。
