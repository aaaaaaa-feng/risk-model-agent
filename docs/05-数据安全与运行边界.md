# 05｜数据安全与运行边界

## 1. 产品承诺

产品不主动把原始数据、客户级记录、逐行评分或模型文件发送到外部 LLM。所有数据、统计、训练、报告和评分默认在本机或用户控制的内网主机运行。

产品不提供 Notebook 或任意用户代码执行入口。但用户所选同步盘、系统代理和本机第三方软件仍超出应用本身的安全控制边界。

## 2. SafeEvidence

允许外发的内容只包括最小必要的聚合证据，例如行列规模、经别名化的字段类型计数、Y 总体分布、阈值、候选模型和不含小样本明细的指标。

禁止：原始行、样例值、完整高基数字段值、文件路径、密钥、手机号/身份证/邮箱等 PII、可逆标识和模型文件。任何分组样本量小于 30 时只保留计数和 `suppressed=true`。

Provider Gateway 对最终实际发送对象统一执行递归字段和值检查以及小样本抑制，禁止“校验 A、发送 B”。出站记录只保存 payload 哈希、Provider、模型、用途、最终状态、上游 request ID（如有）和用量；成功、HTTP 失败、网络失败与响应 schema 失败都必须在 `finally` 路径结算。

## 3. 密钥与 Provider

- 页面不回显密钥；空值保存表示保持不变。
- 环境变量密钥不能在页面伪装成已清除。
- 用户选择清除时，清除优先于同一请求中的新密钥，矛盾请求应拒绝或互斥。
- 默认只使用工作区内的本地受保护文件（目录权限 700、文件权限 600），正常运行不会访问系统 Keychain/Credential Manager；旧版本的钥匙串密钥只在显式一次性迁移时读取，迁移成功后删除旧项。
- Provider 连接测试可使用未保存表单值，但不得把密钥写入日志。

## 4. 本地存储

首次启动会要求选择一个本机工作文件夹；选择结果在应用控制目录保留指针，首次启动所需的引导状态也可能留在控制目录。完成选择后，后续活动数据全部以该工作区为根保存，而不是落在源码仓库。工作区结构固定为：SQLite/设置/密钥/备份/归档，以及 `projects/<project_id>/` 下的 assets、datasets、runs、scores 和 trash。每个项目目录同时保留不含客户数据的项目边界清单，SQLite 仍是事实源。升级后遇到旧版 `notebooks/` 目录或记录时仅保留用于归档恢复，不再执行。

系统识别 iCloud、OneDrive、Dropbox、Google Drive 等同步路径并警告。已有项目运行或存在活动 Run 时不允许切换工作区，避免 Run、Trace 和模型产物被拆到两个目录；切换前应完成归档或新建空工作区。项目归档是可恢复状态；回收站删除和重置必须显式确认。

首次升级：快照旧 SQLite，复制完整旧 runtime，可兼容项目与数据版本迁移，不兼容 Run 以只读记录保留；迁移器不删除源目录。

## 5. 加密迁移包

完整项目包使用 AES-256-GCM。主密钥由用户密码经 scrypt 派生；另生成独立恢复密钥。归档清单列出资源路径、大小和 SHA-256。恢复先在临时目录校验容器 schema、成员数、解压总量、压缩比、路径/符号链接、外键、文件存在性和 hash；无法重映射的路径直接阻断。通过后在单一 SQLite 事务中发布，故障清理临时/半发布目录，启动时回收带恢复标记的孤儿目录。

## 6. 服务与网络

只允许绑定 `127.0.0.1`、`localhost` 或 `::1`，非 loopback 配置直接拒绝。HTTP 边界校验 Host、Origin、跨站写入和临时 SameSite 本机会话。V1 不提供多人认证和内网共享部署承诺。

Windows Tauri 客户端只负责桌面窗口和本地后端生命周期，不复制业务逻辑。它为每次启动选择随机 loopback 端口，并生成两个独立 256-bit 临时凭据：启动凭据验证后端版本、本地运行时与优雅停止；一次性 bootstrap 凭据只供主 WebView 首次导航换取高熵 `HttpOnly` / `SameSite=Strict` Cookie。后端捕获后立即从环境删除两个凭据，避免 Worker 继承；桌面 Uvicorn 关闭 access log，一次性 URL 不进入业务状态或应用日志。启动前校验内置后端的版本化文件清单、路径边界、大小和 SHA-256；校验失败直接阻断。

业务主窗口加载本机 FastAPI 提供的 React 页面，不能调用 Tauri IPC；只有本地启动页拥有最小的状态、重试和打开日志目录权限。桌面模式的公开 health 只返回状态、版本和运行时；除 health、ready、bootstrap 和只认 header 启动凭据的 shutdown 外，首页、静态资源、业务 API、SSE、报告和下载都需要桌面 Cookie，`/api/v1/session` 也只能在该边界后创建现有的写操作会话。Windows 后端与 Worker 使用无控制台进程，并纳入随客户端退出的 Job Object。正常关闭先通过临时凭据保护的 loopback 端点完成 FastAPI lifespan 和本地资源收尾，只有超时或崩溃才强制回收。界面主题、栏位和选中项目等非敏感偏好以 host Cookie 跨随机端口保存；密钥、数据内容和业务字段不进入该 Cookie。上述边界防止误启动、残缺安装和普通文件替换，但在未做 Authenticode 签名时，不声称能够抵抗拥有本机高权限且可同时替换客户端与资源的攻击者。

## 7. 必须阻断

- 原始记录、PII、凭据或危险自由文本进入外部 Provider。
- 路径穿越、归档解包越界和项目目录外产物输出。
- OOT 用于调参/选模、客户跨集合、单类 Y、关联异常膨胀。
- PII、泄漏、其他 Y、贷后不可用字段或主键被人工恢复。
- 模型、报告、评分输入/输出或迁移包 checksum 不一致。

遥测默认关闭；不得在未明确说明时上传业务数据、Prompt 内容或路径。
