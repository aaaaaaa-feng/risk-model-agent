# 07｜模型产出、报告与评分规格

## 1. 唯一事实源

JSON 结构化报告 `risk-model-report/v1` 是唯一事实源。Web、Excel 和单文件 HTML 只能渲染该对象；不得各自重新计算指标。每个文件写入 SHA-256，并登记为 Run Artifact。

## 2. 管理摘要

必须包含项目、Y、数据版本、Champion、Test/OOT AUC 和 KS、最终变量数、绝对排序、质检结论和质检说明。AUC 0.55、KS 0.15 是默认参考，不是硬准入。

质量结论：

- `pass`：确定性/Reviewer 结构检查通过，Test 模型分箱绝对排序满足。
- `conditional`：产物可用，但排序或其他明确风险需业务复核。
- 阻断错误不生成“成功”报告。

## 3. 整体效果

Train、Test、OOT 分别展示样本量、好/坏样本、坏占比、AUC、KS、PR-AUC、Brier、校准证据和适用 PSI。OOT 只在 Champion 冻结后计算。

## 4. 候选模型

每个候选记录算法、状态、校准方法、OOF/Train/Test 指标、Test 排序性、Train-Test PSI、选择分、拟合范围、类别不平衡策略、失败错误码和特征重要性。选择依据不得读取 OOT。

## 5. 变量与分箱

- 报告主视图只展示最终入模变量。
- 记录变量类型、缺失率、Train-only IV、是否人工恢复、恢复理由和重要性。
- 每个变量保存最终分箱、WOE、箱 IV、变量 IV、样本量、好坏样本、坏占比、来源和版本。
- Champion 在各数据集用等频箱展示坏占比、Lift、累计捕获、概率区间和排序性。

## 6. Excel

前三个 Sheet 固定：

1. `总体情况`：管理摘要与 Train/Test/OOT。
2. `入模变量`：最终变量、重要性和最终变量分箱。
3. `模型分箱`：Champion 在各数据集的模型分箱。

后续 Sheet 包括模型对比和 Reviewer 质检记录。排版含标题、冻结窗格、筛选、合理列宽和数值格式。

## 7. 单文件 HTML

所有 CSS、图表数据和报告 JSON 内嵌，可离线打开；不得加载 CDN 或远程脚本。页面包含管理摘要、质量提示、候选对比、整体效果、模型分箱、最终变量和质检记录。

## 8. 模型包

- 评分卡：JSON 规则。
- XGBoost：原生 JSON。
- LightGBM：文本模型。
- CatBoost：CBM。
- sklearn：skops。

包内包含字段合同、数据类型、缺失处理、预处理、模型、校准、评分转换、依赖锁、评分脚本、报告引用和 checksum；不包含训练原始数据。

## 9. 批量评分

输入支持 CSV/Excel。先校验必需字段和类型，再加载冻结模型。输出保留输入列，并新增以模型版本名规范化后的评分列、坏概率、原始分、是否封顶/封底等证据。评分后结果与同一模型训练时预测必须在数值容差内一致。
